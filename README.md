# Login AdminExpress

Página de inicio de sesión responsive hecha con **HTML** y **CSS Grid**.

## Características

- Diseño adaptable a móvil, tablet y escritorio.
- Estructura principal construida con CSS Grid.
- Botón para mostrar u ocultar la contraseña.

## Tamaños de pantalla

| Pantalla | Diseño |
|---|---|
| Móvil (menos de 768px) | Una columna, solo el formulario |
| Tablet (768px a 1023px) | Dos columnas: panel azul y formulario |
| Escritorio (1024px o más) | Dos columnas iguales |

## Cómo verlo

Descarga el proyecto y abre `index.html` en el navegador.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: estilos y diseño responsive.
